# Routes and navigation

Primary navigation follows PRD §10: Overview · Repositories · Knowledge · Search · Tasks · Runs · Reviews · Usage · Settings. ⌘/Ctrl+K opens the command palette from any workspace page.

| Route                                | Screen                                                                                                                                                         | Main API                                                       | Min role for actions     |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------ |
| `/`                                  | **Public homepage**: hero, How it works (scroll-driven), product tour (real screenshots), capabilities, security, boundaries. Static, indexable, no API calls. | none                                                           | —                        |
| `/app`                               | Signed-in entry: redirects to last workspace, onboarding, or sign-in                                                                                           | `GET /me`, `/workspaces`                                       | —                        |
| `/login?next=`                       | Sign in (GitHub). Default destination after sign-in is `/app`.                                                                                                 | GAP-01                                                         | —                        |
| `/onboarding`                        | Create workspace (step 1 of 4)                                                                                                                                 | `POST /workspaces`                                             | any user                 |
| `/integrations/github/callback`      | Completes GitHub App install (validates `state`)                                                                                                               | `POST /integrations/github/complete`                           | admin                    |
| `/w/:slug`                           | Overview: decisions waiting, active runs, recent tasks, repo health, inference share                                                                           | `/runs`, `/tasks`, `/repositories`, `/usage`                   | —                        |
| `/w/:slug/repositories`              | Connected repositories                                                                                                                                         | `GET /repositories`                                            | —                        |
| `/w/:slug/repositories/connect`      | Install app → review permissions → select repos → index (`?onboarding=1` shows stepper)                                                                        | `/integrations/github/*`, `POST /repositories`, `POST …/index` | admin                    |
| `/w/:slug/repositories/:id`          | Index health: progress, coverage, exclusions, limitations, snapshot, re-index, exclusion rules, disconnect                                                     | `/index-status`, `PATCH`/`DELETE /repositories/:id`            | member (re-index), admin |
| `…/:id/code?path=&lines=&commit=`    | File tree + line-addressable viewer, permalinks                                                                                                                | `/tree`, GAP-04                                                | —                        |
| `…/:id/search?q=&lang=&path=`        | Hybrid search with scores and provenance                                                                                                                       | `POST /search`                                                 | —                        |
| `…/:id/ask`                          | Grounded Q&A with citations and limitations                                                                                                                    | `POST /questions`                                              | —                        |
| `…/:id/knowledge`                    | Indexed knowledge + add notes/decisions                                                                                                                        | `/knowledge`                                                   | member                   |
| `…/:id/tasks`                        | Tasks for this repository                                                                                                                                      | `GET /tasks?repository_id=`                                    | member                   |
| `/w/:slug/knowledge`                 | Knowledge across repositories                                                                                                                                  | per-repo `/knowledge`                                          | member                   |
| `/w/:slug/search`                    | Workspace search and Q&A across every indexed repository; each result shows repository and commit (WP-B)                                                     | `POST /workspaces/:id/search`, `POST /workspaces/:id/questions` | —                        |
| `/w/:slug/tasks?status=&repo=&new=1` | Task list; `new=1` opens the create dialog                                                                                                                     | `/tasks`, `POST …/tasks`                                       | member                   |
| `/w/:slug/tasks/:taskId`             | Task detail, runs, start run (mode, branch, budgets)                                                                                                           | `/tasks/:id`, `/runs`, `POST …/runs`                           | member                   |
| `/w/:slug/runs?filter=`              | All runs                                                                                                                                                       | GAP-05                                                         | —                        |
| `/w/:slug/runs/:runId`               | Run workspace: header, stepper, decision banner, live **Timeline** (stages, tools, budget, activity)                                                           | `/runs/:id`, `/steps`, SSE                                     | member (cancel/retry)    |
| `…/runs/:runId/plan`                 | Investigation + plan; edit, approve, reject                                                                                                                    | `/plan`, `PATCH /plan`, `POST /plan-approval`                  | member                   |
| `…/runs/:runId/changes`              | Diff, patch hash, scope check                                                                                                                                  | `/diff`, `/plan`                                               | —                        |
| `…/runs/:runId/verification`         | Passed / failed / skipped / unavailable checks; AI explanation labelled                                                                                        | `/verification`                                                | —                        |
| `…/runs/:runId/review`               | Findings by severity, AI vs deterministic filter, dispositions                                                                                                 | `/review`, `POST …/disposition`                                | member                   |
| `…/runs/:runId/pull-request`         | Evidence gate → approve → compose → create PR                                                                                                                  | `/pr-approval`, `/pull-request`                                | member                   |
| `/w/:slug/reviews`                   | Decision inbox: plans and PRs awaiting approval                                                                                                                | GAP-05                                                         | member                   |
| `/w/:slug/usage`                     | Tokens, runs, local share, cost, budget, by provider                                                                                                           | `/usage`                                                       | —                        |
| `/w/:slug/settings`                  | General                                                                                                                                                        | `PATCH /workspaces/:id`                                        | admin                    |
| `…/settings/members`                 | Members, roles, invite, remove                                                                                                                                 | `/members`, `/invitations`                                     | admin                    |
| `…/settings/integrations`            | GitHub installations, permissions, disconnect                                                                                                                  | `/integrations/github/*`                                       | admin                    |
| `…/settings/ai`                      | Local/hosted inference, default mode, budgets, health check                                                                                                    | `/ai-policy`, `/ai/providers/health-check`                     | admin                    |
| `…/settings/templates`               | Workflow templates: built-ins (read-only) and workspace templates (create, archive) (WP-B)                                                                    | `/workspaces/:id/templates`                                    | admin                    |
| `…/settings/audit`                   | Filterable audit log, paginated                                                                                                                                | `/audit-events`                                                | admin (view)             |
